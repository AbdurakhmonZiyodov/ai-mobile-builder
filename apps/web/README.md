# @amb/web — RIVO frontend

Next.js 16 · React 19 · Tailwind CSS v4 · TypeScript 7

```bash
npm run dev     # :3000
npm run build
```

`.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:4000
```
