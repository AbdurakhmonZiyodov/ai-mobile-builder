## Kontekst

AI SDK 7 `node >= 22` talab qiladi. Ishlab chiqish mashinasida 20.19.5 aktiv
edi, nvm'da 22.16.0 mavjud edi.

## Qaror

Loyiha Node 22 ni talab qiladi. `.nvmrc` va `package.json` dagi `engines`
maydoni qo'yildi.

## Sabab

Versiyani hujjatga yozib qo'yish yetarli emas — noto'g'ri Node bilan ishga
tushirilganda xato AI SDK ichidan, tushunarsiz ko'rinishda chiqadi.
`.nvmrc` va `engines` esa buni boshidayoq aytadi.

## Oqibatlari

- `nvm use` loyiha papkasida to'g'ri versiyani tanlaydi.
- Deploy muhiti ham Node 22 bo'lishi shart.
